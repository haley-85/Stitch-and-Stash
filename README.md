# Stitch & Stash

A planner for quilting, sewing, crochet, and knitting: design quilt tops and get a cut list, track works in progress with timers and notes, and keep an inventory of fabric, notions, yarn, hooks, needles, patterns, and machines.

It's a single file, `index.html`. Open it in a browser, or publish it with GitHub Pages.

When it runs outside Claude, everything is saved in your browser on that device. Use **Home → Back up your work** to save a backup file and **Restore a backup** to move your data to another device. The Claude-powered features (Ask for ideas, label reading, backing and binding ideas, care cards, listings) only work in the Claude-hosted version.
